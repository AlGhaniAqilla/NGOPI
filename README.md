# NGOPI
Nilai Gross Operational  Payload Indicator

Tool Untuk Baca dan Konvert data Tonase Dari Modu PLM/VHMS melalui port Serial RS232 lalu di kirim secara Wireles ke unit Loader, dan juga di kirim melalui UDP agar pengawas yang terhubung melalui Router yang sama (LOCAL AREA) bisa memonitoring secara Real-time, dan data juga di kirim ke server yang akan di tampilkan melalui Webserver agar bisa di lihat secara INTERNASONAL melalui internet
